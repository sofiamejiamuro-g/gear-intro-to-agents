# Infografía Interactiva: Agentes de IA & Gemini Enterprise

Guía de estudio visual e interactiva para estudiantes sobre la evolución de la IA Generativa hacia la Era Agéntica, la anatomía de un agente inteligente, el patrón de razonamiento ReAct, la matriz de decisión arquitectural y el despliegue empresarial con Gemini Enterprise en Google Cloud.

🌐 **Demo en GitHub Pages:** [https://sofiamejiamuro-g.github.io/gear-intro-to-agents/](https://sofiamejiamuro-g.github.io/gear-intro-to-agents/)

---

## 🎯 Contenido de la Infografía

1. **El Cambio de Paradigma (The Agentic Shift)**
   - De responder preguntas (GenAI clásica) a actuar en el entorno (Agentic AI).
   - Consultor estático vs. Empleado ejecutor.

2. **Anatomía del Agente & 5 Pilares Fundamentales**
   - Fórmula: Modelo (Pensar) + Herramientas (Hacer) + Orquestación (Proceso).
   - Los 5 pilares: Consciente del entorno, orientado a metas, autónomo, uso de herramientas y proactivo.
   - Espectro evolutivo: Consultor &rarr; Asistente &rarr; Empleado.

3. **Simulador del Bucle ReAct en Vivo**
   - Visualización interactiva paso a paso: User Request &rarr; Thought &rarr; Action (Tool Calling) &rarr; Observation.
   - Telemetría e inspección de payloads en tiempo real.

4. **Matriz de Decisión & Calculadora Arquitectural**
   - Criterios claros para decidir entre Inferencia Pura (LLM API), Workflow Determinista (Cloud Functions), o Agente Autónomo (Vertex AI / ADK).
   - Calculadora interactiva que evalúa tu caso de uso al instante.

5. **Gemini Enterprise para Entornos Corporativos**
   - Grounding Zero-ETL (Google Drive, BigQuery, Jira, Salesforce, etc.).
   - Ventana multimodal masiva (1M-2M tokens).
   - Privacidad empresarial de grado bancario y control estricto de IAM.
   - 3 casos de uso reales de alto impacto.

6. **Stack Tecnológico en Google Cloud**
   - Capa SaaS (Gemini Enterprise, Google-built Agents).
   - Capa de Plataforma (Vertex AI Agent Builder, Agent Dev Kit - ADK).
   - Capa de Infraestructura (Gemini Pro/Flash, Cloud Run, GKE, Agent Engine).

7. **Fichas de Estudio Interactivas (Flashcards) & Mini-Test**
   - Conceptos clave: Tool Calling, Patrón ReAct, Grounding y Human-in-the-Loop (HITL).
   - Cuestionario de autoevaluación.
